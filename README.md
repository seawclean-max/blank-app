# 🎈 空白应用模板 / Blank app template

一个可以随手改的 Streamlit 小页面。在输入框里写名字，点「打招呼」即可。

A tiny Streamlit page. Type a name and click the greeting button.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://blank-app-template.streamlit.app/)

### 本地运行 / How to run it locally

1. 安装依赖 / Install the requirements

   ```
   pip install -r requirements.txt
   ```

2. 启动应用 / Run the app

   ```
   streamlit run streamlit_app.py
   ```
